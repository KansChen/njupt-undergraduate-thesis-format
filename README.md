# NUPT Undergraduate Thesis Format

## Workflow

1. Identify the task type: create a thesis structure, format an existing DOCX, audit compliance, or answer a rule question.
2. Read `references/format-rules.md` before applying or judging detailed requirements.
3. For DOCX editing, preserve existing content and user edits. Use document-aware tools when available, then render or inspect the output when the user asks for finished formatting.
4. Check requirements in this order: required components, page setup, line spacing, fonts and heading levels, body numbering, figures/tables/formulas, references, appendices, and binding order.
5. Report unresolved ambiguities explicitly, especially when the source document says "see template" but no template is provided.

## Key Decisions

- Treat this skill as a formatting and compliance standard, not as a writing-quality rubric.
- Apply the provided school rules exactly when they are specific.
- When the source only says "detailed requirements see template", do not invent template-only details. Ask for the template or mark the item as template-dependent.
- For undergraduate thesis DOCX work, combine this skill with a DOCX/document skill if one is available.

## Common Tasks

### Create an outline

Create the required main sequence: title, Chinese abstract and keywords, English abstract and keywords, table of contents, body, conclusion, acknowledgements, references, appendices when needed.

### Format a DOCX

Set A4 page layout, margins, header/footer, line spacing, title styles, body fonts, page numbers, and numbering rules from `references/format-rules.md`. Keep form pages and signatures intact.

### Review compliance

Return findings grouped by severity. Include concrete locations when possible, and distinguish rule violations from items that cannot be verified without the official template or cover/forms.

### Fix references

Use the reference examples in `references/format-rules.md` for journals, books, proceedings, standards, patents, electronic sources, newspapers, dissertations, and technical reports. Ensure in-text citations use bracketed Arabic numerals matching the reference list.

## Verification Checklist

- Required sections and binding order are present.
- A4 page settings match the school rule.
- All thesis content and headings use 1.25 line spacing.
- Section heading fonts and body fonts match the school rule.
- Body chapters use `第一章`, `第二章`; chapters start on new pages.
- Lower-level headings use `1.1`, `1.1.1`; heading depth normally does not exceed level 3.
- Tables, figures, and formulas are numbered by chapter and continuous.
- References follow the required type-specific patterns.
- Appendices, if present, start on separate pages and use appendix-specific numbering.
